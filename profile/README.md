## System Colonisation Contractors 👋

 We are the System Colonisation Contractors or the SCC for short. in the game Elite:Dangerous, we help commanders in need of colonisation materials or haulers find the help requested from our job board.

## contributing

join the org, let us know what you can work on, and we'll assign you some changes to make.  You will need the following technologies;

 - VS2026 Community or better
 - vscode (can replace the above, if you really know what you're doing)
 - Docker Desktop
 - local or docker postgres server
 - a Discord developers account
 - a personal Discord guild for local testing
